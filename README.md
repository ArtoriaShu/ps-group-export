# 图层组分批导出 v1.1.0

作者：Shu

独立的 Photoshop CEP 插件，插件 ID 为 `com.shu.groupexport`，菜单为 **图层组分批导出**。设置、安装目录和代码均独立于其他插件。

## 安装

需要支持 CEP 扩展的 Photoshop 桌面版（manifest 最低版本 20.0 / CC 2019）；Windows 提供普通用户安装器，无需管理员权限。尚未在真实 Photoshop 中完成兼容性验证。

1. 完整解压 ZIP，然后完全退出 Photoshop。
2. Windows：双击 `install.bat`。macOS：双击 `install-mac.command`；若系统不允许直接打开，可在终端运行 `bash /完整路径/install-mac.command`。
3. 重启 Photoshop，在 **窗口 → 扩展功能（旧版）→ 图层组分批导出** 打开面板。部分版本的菜单叫“扩展功能”。

安装器会给当前用户安装扩展，并为 CSXS 9–12 启用 `PlayerDebugMode`，以加载此未签名 CEP 扩展。macOS Apple Silicon 原生模式下部分 Photoshop 版本不支持 CEP，需使用支持 CEP 的 Photoshop 运行模式。

## 使用

1. 在面板顶部选择读取方式：
   - **直接选图层**：在图层面板中按住 Ctrl（Windows）或 Command（macOS）多选需要分别导出的图层或图层组（连续的可点第一个、按住 Shift 点最后一个）。祖先组无需一起选择。
   - **选父级，导出其下图层**：只选图层的上一级（可多选），它下面的每个直接子项（图层组或普通图层，如一组切图图层）各导出一张；子图层组里更深的内容不再拆开。父级里如有不想单独导出的图层（如底图），读取后点 × 去掉。
2. 点击 **读取选中的图层**（或 **读取父级下的图层**）。清单显示文件夹名称及完整分组路径；点 × 可移除条目（移除的图层不导出，并在其他图片中保持隐藏）。重新读取会替换整份清单。
3. 选择 **整个画布／画板**（默认）或 **按内容裁切**。
4. 选择保存目录，点击 **导出 N 个文件夹**。可勾选 **按父文件夹分目录保存**：每张图保存到以其上一级组命名的子目录（如 `所选目录\B\图层 01.png`），子目录不存在时自动创建；顶层文件夹没有上级组，直接保存在所选目录。

例如 `父组 A → B → 图层 01、图层 02`：用“直接选图层”时选中“图层 01”和“图层 02”；用“选父级，导出其下图层”时只选 B。两种方式都无需把 A 加到清单。插件自动开启当前图层及其所有祖先组，并隐藏清单中的其他图层。不同父组下面的图层也能放在同一份清单里，分别导出，不做组合。

清单里的图层分属不同父级时（如 `B/图层 01` 和 `C/图层 03`），导出 B 的图层时会把 C 整个隐藏，C 里直接放的底图、装饰等也不会出现，反之亦然。两者共同的上级（如 A）保持开启；所有父级之外的公共图层按原显示状态保留。

- **按内容裁切**：裁切范围与“4 倍数导出”插件（Photoshop 原生“导出为”）一致：图层组单独合并（含其内部可见图层、自身蒙版和图层效果，如投影），普通图层连同效果、智能对象和文字一起栅格化，再取去掉透明边后的像素范围；再限制在所属画板或画布内。公共图层和其他图层不影响裁切尺寸，但会按原显示状态出现在裁切范围内的最终合成里。祖先组的蒙版不参与测量，若它裁掉了图层的一部分，图片边缘会留透明。
- 选中的文件夹本身是画板时，导出整个画板（与原生导出画板一致）。
- **导出整个画布／画板**：使用所属最近一层画板的矩形；没有所属画板时使用整个文档画布。保留位置和留白。
- 两种模式都保留子文件夹内部原有的显示状态，不强制打开其全部子图层。
- 输出为 8 位 sRGB PNG。尺寸不补到 4 的倍数，不缩放，不翻译名称。
- 每张文件使用对应文件夹名称加 `.png`。操作系统不支持的字符会替换为 `_`，Windows 保留名会加 `_`，过长名称会截断；清单会提示调整后的名称。同名文件自动添加 ` (2)`、` (3)` 等后缀。
- 不会覆盖已有文件。出错会停止后续导出，已经保存的文件保留。
- 取消会等待当前 Photoshop 渲染结束，放弃当前图片的最终保存，再停止任务。已保存的图片保留。
- 每批只复制一次 PSD（临时文档 `__groupexport_work__`），所有图层共用这份副本，批次结束、取消或出错时自动关闭。原 PSD 的图层显示、选择和标尺单位都不变，也不会保存原 PSD。
- 标尺单位为厘米、毫米或百分比时同样按像素计算。
- 位图、灰度、CMYK、Lab、索引颜色等模式会转换为 RGB；32 位和多通道 PSD 需先转换模式。
- 从清单中移除（×）的图层在导出其他图层时仍会被隐藏，不会混入其他图片。
- 读取后如果编辑了 PSD，需重新读取清单。请在导出期间等待任务结束后再操作 Photoshop。
- 一批处理当前一份 PSD；切换 PSD 后重新选择并读取。当前不包含扫描磁盘中多个 PSD 的无人值守流程。

不能同时选中一个图层组和它内部的图层作为独立导出项。没有可见内容的图层或图层组在裁切模式会报错（例如调整图层）；请确认图层内容和蒙版。

## 日志与问题反馈

面板右下角有 **复制诊断信息** 和 **日志目录**。导出出错时点 **复制诊断信息**，把复制的文字发给开发者即可：里面有 Photoshop 版本、当前文档（尺寸、模式、位深、图层数）、面板设置、读取的文件夹清单，以及每张图各步骤的用时和裁切范围。若无法自动复制，诊断信息会显示在面板里的文本框中，按 Ctrl+C 复制。

日志按天保存 7 天：Windows 在 `%APPDATA%\GroupExport\logs`，macOS 在 `~/Library/Logs/GroupExport`。

## 卸载

退出 Photoshop 后，Windows 运行 `uninstall.bat`，macOS 运行 `uninstall-mac.command`。只删除本插件，不删除导出的 PNG，不修改其他插件。不会撤销共享的 CEP 调试设置，以免影响其他未签名扩展。

## 开发与验证

无需 npm 安装依赖。运行 `npm test`；运行 `npm run build` 生成安装包。

`dev/preview.html` 是可交互的浏览器演示，使用模拟 PSD 和模拟导出；通过 `python3 -m http.server 8765` 启动后访问 `/dev/preview.html`。

自动测试覆盖宿主分组状态、嵌套祖先、范围、命名冲突、取消、错误恢复和原文档不变。模拟宿主无法验证 Photoshop 的实际像素合成效果；发布前应在真实 Photoshop 中检查文件夹单独合并后的裁切尺寸、父级蒙版、阴影、混合模式、画板背景和裁切尺寸。剪贴组依赖旁边的基底图层时，隔离测量的可见范围可能与完整合成不同，此类文件尤其需要核对裁切结果。

宿主使用 Adobe 的 ExtendScript 文档复制、合并副本和裁切接口：[Adobe Photoshop JavaScript Reference](https://github.com/Adobe-CEP/CEP-Resources/blob/master/Documentation/Product%20specific%20Documentation/Photoshop%20Scripting/photoshop-cc-javascript-ref-2019.pdf)。
